# Tepore

Diario delle emozioni per iPhone (PWA). Nessun backend: i dati restano nel dispositivo.

- `npm i` → `npm run dev` (watch SCSS) → `npm run serve`
- Deploy: `npm run build`, poi pubblica la cartella `src/` (Netlify, Vercel, qualsiasi hosting statico, HTTPS).
- Su iPhone: Safari → Condividi → Aggiungi alla schermata Home.
